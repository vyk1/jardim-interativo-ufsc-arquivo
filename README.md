> O website visa disponibilizar informações acerca das plantas medicinais e tóxicas dentro da veterinária a população
  
## 💻 Pré-requisitos

  
Antes de começar, verifique se você atendeu aos seguintes requisitos:

* Você instalou a versão `12.22.12` ou superior do `NodeJS`

* Você instalou a versão `6.14.16` ou superior do `NPM`

* Você instalou uma versão do `Firebase CLI` em sua máquina

* Você tem uma máquina com Sistemas Operacionais `Windows, Linux ou Mac`

* Você leu a documentação. 

## 🚀 Instalando
  

Para instalar as dependências, vá no diretório raiz e execute:
```
npm run install
```  

## ☕ Usando em Ambientes

### Desenvolvimento/Teste (local)
Para acessar este ambiente, vá no diretório raiz e execute:
```
npm run start
```

### Produção
O site Jardim Interativo foi hospedado nos servidores da empresa Google em Firebase.

Para lançar uma nova versão, deverá ser necessário fazer push manual via package.json:

```
npm run deploy
```

Isso engatilhará o comando de `build` da aplicação e posteriormente será implantado caso sua configuração esteja correta e com a conta da aplicação.

No caso de eventuais dúvidas, utilizar a documentação ou [entrar em contato](#Contato).
